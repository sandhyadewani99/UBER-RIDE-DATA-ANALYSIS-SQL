# UBER-RIDE-DATA-ANALYSIS-SQL

📌 Project Overview
This project analyses Uber ride data using SQL to uncover business insights related to ride demand, driver performance, passenger behaviour, payment methods, and fare trends.  

The objective of this project is to demonstrate SQL skills such as data cleaning, filtering, joins, aggregations, subqueries, grouping, and business insight generation.

---

 📂 Dataset Information

The project uses three tables:

 1️⃣ Drivers Table
- driver_id  
- driver_name  
- join_date  
- rating  
- total_rides  
- earnings  

 2️⃣ Passengers Table
- passenger_id  
- passenger_name  
- signup_date  
- total_rides  
- total_spent  
- rating  

 3️⃣ Rides Table
- ride_id  
- driver_id  
- passenger_id  
- pickup_location  
- dropoff_location  
- ride_distance  
- ride_duration  
- ride_timestamp  
- fare_amount  
- payment_method

📈 Business Questions Solved

Some key questions solved in this project:

1. Total number of rides  
2. Average ride duration  
3. Top drivers by earnings  
4. Most common pickup locations  
5. Payment method distribution  
6. Passengers with highest spending  
7. Weekday average fare analysis  
8. Monthly fare trends  
9. Common pickup-dropoff routes  
10. Drivers completing long-distance rides  

---

 🔍 Key Insights

- Weekday rides show strong commuter demand with higher average fares.  
- High-performing drivers contribute significantly to platform earnings.  
- Cash and Credit Card are the most preferred payment methods.  
- Certain locations act as major ride demand hubs.  
- A few passengers generate high lifetime spending.  
- Monthly fare trends indicate seasonal ride demand patterns.
